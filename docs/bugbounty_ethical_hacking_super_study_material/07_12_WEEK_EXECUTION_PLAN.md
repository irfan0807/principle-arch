# 07 - 12 Week Execution Plan

## Weeks 1-2: Foundations + Lab Build
- Complete legal/scope module.
- Build lab stack and tooling.
- Practice manual HTTP inspection and auth flows.

## Weeks 3-5: Web Vulnerability Core
- Deep practice on access control, injection, XSS, CSRF, SSRF.
- Solve labs with written repro notes.
- Build personal checklist from recurring mistakes.

## Weeks 6-7: API Security
- Focus on BOLA/BFLA/mass assignment/rate limiting.
- Practice token and authorization edge-case testing.
- Submit at least 3 full mock reports.

## Weeks 8-9: Bug Bounty Pipeline
- Build recon workflow and prioritize target areas.
- Run daily structured hunting blocks.
- Measure findings and reporting quality.

## Weeks 10-11: Advanced Domains
- Cloud/container/mobile/internal concepts.
- Practice one domain deeply based on your target programs.
- Add detection-minded notes for each weakness.

## Week 12: Consolidation
- Run full-scope mock engagement.
- Produce final portfolio package.
- Define next 90-day specialization plan.

## Weekly Cadence Template
- 5 days study/practice
- 1 day review + report writing
- 1 day rest or light reading

## Minimum Weekly Output
- 10+ focused practice hours
- 5+ validated test cases logged
- 1 polished report artifact
