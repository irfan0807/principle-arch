# Checklists and Templates

## Pre-Engagement Checklist
- Scope reviewed
- Authorization verified
- Out-of-scope list saved
- Safe testing constraints documented
- Contacts and escalation path documented

## Recon Checklist
- Subdomains mapped
- Technology stack identified
- Key endpoints and parameters cataloged
- Auth boundaries mapped
- High-value business flows identified

## Vulnerability Validation Checklist
- Issue reproducible consistently
- Works from clean session
- Impact validated with minimal-risk proof
- False-positive causes checked
- Mitigation options identified
