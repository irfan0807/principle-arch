# 05 - Adversary TTPs (Defensive View)

This section addresses "black hat hacking" topics safely by focusing on:
- Behavior patterns
- Detection opportunities
- Prevention and response

## ATT&CK-Style Thinking
- Initial access patterns
- Execution and persistence behavior
- Privilege escalation indicators
- Credential access patterns
- Discovery and lateral movement behaviors
- Exfiltration signals

## Defensive Mapping Workflow
1. Identify likely attacker objective.
2. Map possible techniques (high-level only).
3. Define telemetry required to detect behavior.
4. Add prevention controls and compensating controls.
5. Build response playbook and tabletop scenario.

## Detection Engineering Basics
- High-value logs and normalization
- Alert quality versus alert quantity
- Behavioral over signature-only detection
- False-positive tuning cycles

## Incident Response Readiness
- Triage templates
- Containment decision matrix
- Evidence preservation basics
- Post-incident hardening loop

## Red Flags in Real Environments
- Suspicious auth anomalies
- Unusual privilege assignments
- Unexpected egress patterns
- Script/tool execution from uncommon paths

## Outcome
- You understand attacker tradecraft without learning illegal exploit playbooks.
- You can convert threat intel into practical defensive controls.
